# 디자인 출처와 적용 범위

## Taste Skill

- 웹사이트: https://www.tasteskill.dev/
- 소스: https://github.com/Leonxlnx/taste-skill
- 소스 라이선스: MIT, Copyright (c) 2026 Leonxlnx.
- 확인한 소스 버전 표기: `tasteskill 2.5.1`의 `design-taste-frontend`.

실제 Chromium 1440px 화면을 열어 확인했다. 웹사이트 본문 computed style은 배경 `rgb(248, 244, 238)`, 잉크색 `rgb(26, 14, 8)`, 첫 제목은 84px의 Google Sans Flex였다. 첫 화면은 어두운 갈색에서 주황색을 거쳐 종이색으로 이어지는 히어로, 작은 떠 있는 내비게이션, 큰 제목, 실제 제품 화면의 조합이었다. 웹사이트와 GitHub 스킬의 배포 시점·내용은 같다고 가정하지 않는다.

학습 문서에는 다음 원리만 새로 구현했다.

- 따뜻한 종이 바탕, 짙은 잉크와 제한된 주황 강조색.
- 분명한 제목 계층, 정렬된 좌우 가장자리, 작은 모드 전환부.
- 장식용 대시보드 대신 실제 코드와 데이터 흐름을 중심 소재로 사용.
- 모바일에서도 코드 자체의 스크롤만 허용하고 본문은 읽기 너비를 유지.

사이트의 로고·사진·폰트 파일·스크린샷·CSS·문구·효과·템플릿은 재배포하지 않는다. 랜딩 페이지용 고정 화면 높이, 무작위 레이아웃 추첨, 셰이더, 강제 모션은 읽기 도구에 적용하지 않는다. 이 문서의 색 측정값은 출처 관찰이며 전체 디자인 시스템을 복제했다는 뜻이 아니다.

## Impeccable

- 소스: https://github.com/pbakaus/impeccable
- 라이선스: Apache-2.0, Copyright 2025 Paul Bakaus.
- 제작 환경에 `impeccable` 스킬과 검사 도구를 설치했다. 이 저장소에는 도구 자체를 포함하지 않는다.

읽기 중심 UI 원칙을 적용한다: 본문은 일반 서체, 코드는 고정폭, 명시적인 이전/다음과 목차, 네이티브 버튼·details·label, 명확한 포커스, 반응형 레이아웃. 검사 도구의 경고와 실제 시각 검토는 서로 다른 근거로 기록한다. 자동 검사가 접근성 전체나 학습 효과를 보증하지 않는다.

## Archify

- 학습 대상에 연결 구조가 실제로 필요하고 Archify가 설치되어 있으면 별도 JSON과 검증된 HTML 다이어그램을 만든다.
- 원문 코드·스냅샷과 다이어그램을 혼동하지 않는다. `finalize` 영수증 없이 검증 완료라고 말하지 않는다.
- 이 스킬의 필수 의존성은 아니며 Archify 엔진이나 에셋을 재배포하지 않는다.

## 개인정보와 효과 주장

예제는 새로 작성한 가상 코드다. 실제 프로젝트의 코드, 사용자 답변, 경로는 기본적으로 로컬 파일에만 남긴다. 공개 예제에 옮기기 전 별도 승인과 비밀정보 검토가 필요하다. 이 스킬은 예측·회상·자기 설명을 돕는 도구이지, 인지 저하를 예방하거나 지능을 개선한다고 입증된 의료·건강 도구가 아니다.

## 실제 제작 검증

Impeccable의 최종 1440×1000 URL 검사에는 `cream-palette` 경고 하나가 남았다(종료 코드 2). 사용자가 지정한 Taste 사이트에서 관찰한 종이색을 의도적으로 채택했으므로 유지했으며, 경고를 숨기거나 검사 통과라고 표현하지 않았다. 초기 검사에서 나온 placeholder 대비와 제목 줄 균형, 불필요한 작은 히어로 라벨/중첩 프레임은 수정했다.

실제 Chromium에서는 390/768/1440px 가로 넘침, 학습/설명 전환, 해설의 키보드 펼치기, 목차·이전/다음·뒤로가기, JavaScript 없는 설명 보기, 악성 문자열의 비실행 표시를 확인했다. 이는 물리 모바일 기기 테스트나 WCAG 전체 적합성 인증은 아니다.
